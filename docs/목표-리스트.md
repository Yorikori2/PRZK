## 2. 왼쪽 툴바 개선: 방식 후보

지금 툴바(🎒 🧬 🛠 🧱 🏠 🔊)는 왼쪽 가운데에 세로로 붙어 있어요.

| 방식 | 설명 | 장점 | 단점 |
|---|---|---|---|
| **A. 아래에서 끌어 올리는 서랍** (말씀하신 방식) | 왼쪽 아래에 손잡이(☰)만 두고, 위로 쓸어 올리면 버튼이 아래→위로 펼쳐지고, 내리면 접힘 | 평소엔 화면이 넓음 · 엄지 위치에서 바로 닿음 | 조이스틱 영역과 겹치지 않게 손잡이를 조이스틱보다 왼쪽·아래 가장자리에 둬야 함 |
| **B. 상호작용 버튼 길게 누르기 → 부채꼴 메뉴** | 오른쪽 상호작용 버튼을 길게 누르면 버튼 6개가 부채꼴로 펼쳐지고, 손가락을 밀어서 고름 | 한 손(오른손)으로 전부 조작 · 툴바 공간이 아예 필요 없음 | 처음엔 숨겨져 있어서 알려줘야 함 |
| **C. 상황에 따라 버튼만 보이기** | 🏠은 거점 근처에서만, 🧱은 바리케이드 재료가 있을 때만 보이는 식으로 버튼 수를 자동으로 줄임 | 버튼이 2~4개로 줄어 깔끔함 | 버튼 위치가 상황마다 바뀜 |
| **D. 접히는 툴바** | 지금 자리 그대로, 맨 위 ◀ 버튼으로 한 줄짜리 아이콘으로 접었다 펼침 | 가장 간단 · 지금 배치와 비슷 | 공간 절약 효과가 작음 |

**추천:** **A + C 조합**
- 평소에는 손잡이만 보여서 화면이 넓어요.
- 펼쳤을 때는 지금 필요한 버튼만 나와서 짧아요.
- UI 편집(⚙)으로 손잡이 위치도 옮길 수 있게 하면 왼손잡이도 편해요.

## 6. 맵 확장

**지금 맵:** 5248 × 2624 px · 거리 블록 5×3칸 (블록 896×704, 도로 128) · 건물 구역 14곳 · 수색 가능한 가구 575개 · 걸어서 가로 약 48초, 세로 약 24초

**키울 수 있어요.** 맵이 블록 격자로 만들어져서 블록 수만 늘리면 돼요.

| 크기 | 픽셀 | 넓이 | 걸어서 가로 |
|---|---|---|---|
| 지금 5×3 | 5248 × 2624 | 1배 | 약 48초 |
| 7×4 | 7296 × 3456 | 약 1.8배 | 약 66초 |
| 8×5 | 8320 × 4160 | 약 2.5배 | 약 76초 |

**넓힐 때 필요한 일**
- 새 블록에 들어갈 건물: 기존 종류의 변형(두 번째 주택가·아파트) + 새 종류(예: 병원, 쇼핑몰, 공원, 주차 타워, 항구 창고)
- 기존 저장과의 호환: 새 블록을 오른쪽·아래쪽에 붙이면 기존 건물 위치가 그대로라 이어하기가 돼요. 이전 확장 때처럼 안내 문구를 띄워요.
- 미니맵 축소 비율, 좀비 수, 웨이브 출현 범위 조정
- 이동이 길어지니 차량(지금 1대) 추가나 거점 간 빠른 이동 검토
- 성능: 바닥은 필요한 부분만 그리는 방식이라 큰 부담은 없지만, 넓힌 뒤 60fps를 다시 검사해요

## 7. 앱으로 만들기

**만들 수 있어요.** 지금 게임은 HTML·자바스크립트·캔버스로만 되어 있어서 앱으로 감싸기 쉬워요.

| 방법 | 결과 | 필요한 것 | 여기서 할 수 있는 부분 |
|---|---|---|---|
| **① 홈 화면 앱 (PWA)** | 폰 홈 화면에 아이콘 · 전체 화면 · 오프라인 실행 | 웹 주소(호스팅) | 전부 (아이콘, 설치 설정, 오프라인 저장) |
| **② 안드로이드 앱 (Capacitor)** | 플레이스토어에 올리는 APK/AAB | 구글 개발자 계정(1회 $25) · 빌드용 Android SDK | 앱 프로젝트 구성까지 · 빌드는 SDK 설치 가능 여부에 따라 여기서 또는 직접 |
| **③ 아이폰 앱 (Capacitor)** | 앱스토어 앱 | 맥 컴퓨터 + Xcode · 애플 개발자 계정(연 $99) | 프로젝트 구성까지 · 빌드와 심사는 맥에서 직접 |

**앱으로 만들 때 손볼 것**
- 저장 데이터 백업·불러오기 (앱을 지우면 저장도 지워지므로)
- 화면 방향 고정 옵션, 뒤로 가기 버튼 처리, 소리 자동 재생 처리
- 앱 아이콘·시작 화면, 저사양 폰 성능 점검

**추천 순서:** ① PWA로 먼저 폰에 설치해서 써 보기 → 괜찮으면 ② 안드로이드 → ③ 아이폰
